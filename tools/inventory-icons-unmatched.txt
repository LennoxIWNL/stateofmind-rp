# Items with a poor or missing inventory icon
#
# 205 of 605 declared items now carry a photoreal icon.
# This file is the remainder: 250 on stock illustrated art and
# 150 with no image file at all, marked (m), which render blank.
#
# None of these could be matched against the public GPL packs already used:
#   TenTypeeek/OX_inventory-reimagined   (168 images)
#   aifazi/items-images                  (3,476 images)
#
# The grouping below shows why. What is left is script-specific rather than
# generic: a particular restaurant's menu, weapon tint swatches, tuning parts,
# gem tiers, GPU models. No general-purpose pack carries those names, and
# checked by hand, the near-misses were different objects (a stone hatchet for
# `stone`, a diamond-shaped key for `diamond`), not variants.
#
# To close it: drop a pack into ox_inventory/web/images/ using these exact
# filenames. Items left alone stay on stock art deliberately, because a wrong
# icon is worse than an inconsistent one.
